<h1 style="color: red;">Melanoma_Skin_Cancer_Detection</h1>

## 💡 Overview ##

This project uses deep learning techniques to detect melanoma skin cancer from images. The application identifies whether the uploaded skin image is melanoma or not.

---

## 🚀 To Run the Project ##
   ---
    python .\app.py
